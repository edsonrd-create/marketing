# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.1.x   | :white_check_mark: LTS |
| < 1.1   | :x:                |

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

If you discover a security issue in Marketing Brain, report it responsibly:

1. Email or contact the maintainers listed in [CODEOWNERS](.github/CODEOWNERS).
2. Include a clear description, affected component, reproduction steps, and impact assessment.
3. Allow reasonable time for triage and remediation before public disclosure.

## What to Include

- Marketing Brain version (`VERSION` file or `npm run build:info` when available)
- Affected MCP server or package
- Proof of concept (if available)
- Suggested fix (optional)

## Response Expectations

- **Acknowledgement:** within 5 business days
- **Status update:** within 14 business days
- **Fix or mitigation plan:** depends on severity; critical issues are prioritized

## Scope

This policy covers the Marketing Brain monorepo, including MCP servers, shared libraries, CLI tooling, Docker images, and CI/CD configuration.

## Safe Harbor

We support good-faith security research that follows this policy and avoids privacy violations, service disruption, or data destruction.
